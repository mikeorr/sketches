Spysol Help

Spysol is a variation of the Spider card game.

About Spysol

Spysol was created by Mike Orr. This is version 6. The name "Spysol" is a portmanteau of Spider, Python, and Spy.

Version 5 is written in modern vanilla Javascript and CSS. The only library is random-seedable by Chris Akroyd to shuffle the cards and choose the suit colors.

The suit colors are managed by CSS. The cards are HTML <div>'s with classes for the suit and rank. Two CSS variables set the base hue for the two suits. These feed into HSL color values for the suit-rank shades.
